# Witcher Fan Site

A fan site dedicated to The Witcher universe, built with modern web technologies. This project features immersive animations, responsive design, and sections highlighting the heroes, stories, and soundtrack of the acclaimed series.

## Features

- **Hero Section:** An immersive introduction to the site.
- **Characters Section:** Interactive cards (styled like Gwent cards) displaying popular characters.
- **Story Section:** Highlights of the overarching narrative.
- **Soundtrack Section:** An appreciation of the iconic Witcher music.
- **Smooth Animations:** Powered by GSAP for a rich, interactive experience.

## Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Library:** [React](https://react.dev/)
- **Animations:** [GSAP](https://gsap.com/) & `@gsap/react`
- **Styling:** SCSS / Sass
- **Code Formatting & Linting:** [Biome](https://biomejs.dev/)
- **Language:** TypeScript

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (version 20+ is recommended). This project uses `pnpm` as its package manager.

### Installation

1. Clone the repository
2. Install the dependencies:
```bash
pnpm install
```

### Development Server

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Scripts

- `pnpm dev`: Starts the local development server.
- `pnpm build`: Builds the application for production.
- `pnpm start`: Starts the production server.
- `pnpm lint`: Runs Biome to check the code for linting and formatting issues.
- `pnpm format`: Runs Biome to format the codebase.
